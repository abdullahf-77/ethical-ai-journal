# Ethical AI Journal

A UNESCO Centre / ICAIRE initiative that curates AI-ethics research against a
consolidated 7-domain taxonomy (286+ subdomains, built from twelve source
frameworks) and publishes it as a browsable journal site.

**Live site:** https://abdullahf-77.github.io/ethical-ai-journal/

This repository contains two independent projects that share the same
taxonomy data:

```
ethical-ai-journal/
  frontend/    React + TypeScript + Tailwind site (this is what's deployed to GitHub Pages)
  pipeline/    Python backend that discovers, deduplicates, and classifies papers
                against the taxonomy, exporting the JSON the frontend reads
  .github/workflows/   CI: builds frontend/ and deploys it to GitHub Pages on push to main
```

## Frontend (`frontend/`)

A frontend-only prototype — no backend calls at runtime. Domain/subdomain
data and classified papers are baked in at build time from
`pipeline`'s taxonomy and export JSON.

- **Stack:** Vite, React, TypeScript, Tailwind CSS v4, React Router, Framer Motion
- **Pages:** Home (hero, news/submission placeholders, taxonomy preview) →
  Taxonomy Hub (search + 7 domain cards) → Domain page (subdomains with
  their papers listed inline)
- **Dark mode**, responsive layout, real arXiv/OpenAlex paper links

### Run locally

```bash
cd frontend
npm install
npm run dev        # http://localhost:5173
npm run build       # production build to frontend/dist
```

## Pipeline (`pipeline/`)

Discovers academic papers (arXiv, Semantic Scholar, OpenAlex, Crossref),
deduplicates them, classifies them against the taxonomy using an embedding
pre-filter + LLM confirmation pass (Claude or Gemini), and exports the result
to Google Sheets and JSON. See `pipeline/README.md` for full documentation.

### Run locally

```bash
cd pipeline
pip install -r requirements.txt
cp .env.example .env   # fill in your own LLM + Google Sheets credentials
python scripts/run_pipeline.py --domains TD1 --sources arxiv openalex --results-per-query 5
```

`pipeline/data/` (raw/processed/classified/excluded/exports) is generated by
running the pipeline and is not tracked in git — running the commands above
recreates it locally.

## Deployment

`frontend/` is built and published to GitHub Pages automatically by
`.github/workflows/deploy-pages.yml` on every push to `main`. No build output
is committed to the repository — GitHub Actions builds it fresh each time.

## Taxonomy

`pipeline/taxonomy/taxonomy_v2_7domains.json` is the source of truth for the
7-domain taxonomy (see `pipeline/taxonomy/taxonomy_v2_grouping_rationale.md`
for how it was consolidated from twelve source frameworks). The frontend's
`frontend/src/data/taxonomy.json` and `frontend/src/data/papers.json` are
generated from it and from the pipeline's classified-paper exports.
